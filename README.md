# Korea Data Center Development Map

공개 자료 기반 대한민국 데이터센터 사업 현황 지도 (초기 베타).

- 지도: index.html (Leaflet / OpenStreetMap)
- 기준일: 2026-10-12
- 데이터: 37건, 공개 시장보고서 및 보도자료에서 추출
- 검색: 지역/단계/사업명, 근거자료 바로가기
- 경고: 모든 지도핀은 **시·군·구 수준의 참고 좌표**이며 실제 대지 위치가 아님. 인허가 단계와 준공 예정일은 최신 행정증명과 다를 수 있음.
- 표기 용량은 자료마다 수전/IT/사업규모가 혼합되어 있으므로 합산 금지.

## 후속 품질관리
1. 건축행정시스템·지방자치단체 심의의결·건축허가 자료 대조.
2. 시설별 지번 및 지오코딩, 공개 가능 주소 확인.
3. 뉴스 기사 날짜, 각 단계 실제 이행일, 예상일을 분리.
4. 추가 사업지, 출처 URL, 최종 검증일을 관리.
